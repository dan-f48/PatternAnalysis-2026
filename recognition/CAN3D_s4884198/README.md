# COMP 3710 Assignment 3 README
### Dan Fuller  

As a newly recruited engineer, you must present a one-page written feasibility review to your

project manager (tutor) before expending extensive computing resources or committing to an unviable
architecture. The review must address the open engineering dilemma of your chosen domain and cover:
1. User Need, Scope & Acceptance Criteria: The intended user, prototype purpose, and 3–5
testable acceptance criteria addressing the domain’s open dilemma, including an operational/resource
constraint (e.g., peak VRAM, runtime).
2. Model Choice & Course Concepts: The proposed dataset configuration, model architecture,
chosen difficulty band, and how course concepts and literature support the choices.
3. Preliminary Feasibility Evidence: An initial data audit, baseline smoke-test experiment, or
measured resource estimate. A fully trained final model is not required.
4. Risks, Budget & Fallback: Key technical risks, computing budget, the next planned experiment,
and a workable fallback.
